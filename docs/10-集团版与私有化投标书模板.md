# 集团版 / 私有化部署 · 投标书模板

> **适用场景**：超大型钢贸集团、上市/拟上市钢贸公司、央/国企采购、产业园区集采、钢厂下游统一授权采购  
> **采购规模**：年订阅 ¥10,800 起，私有化部署 ¥80,000 起，大型集团整体方案常见区间 ¥30 万–¥300 万  
> **使用方式**：以本模板为骨架，结合具体客户需求与招标文件填充；保留所有 □ 待填字段  
> **法务复审项**：第 5/6/9/11 章及《商务承诺函》  
> **建议页数**：正本 80–120 页（含附件），技术标 + 商务标分册

### 5.2 部署模式（提供三选项）

| 模式 | 适用 | 优点 | 缺点 | 报价 |
|---|---|---|---|---|
| **公有云 SaaS** | 大多数集团 | 上线最快 / 持续升级 | 数据在我方云 | 含集团版年费 ¥10,800 起 |
| **专属云 SaaS** | 上市/合规要求高 | 数据隔离 / 网络专线 | 升级需窗口 | + ¥30,000/年 |
| **私有化部署** | 央/国企 / 集团内部审计要求严 | 数据 100% 在客户内网 | 升级周期长 | ¥80,000 一次性 + ¥20,000/年维保 |

> 客户可在**项目实施前 30 天**确定最终模式；本投标按 [ ____ ] 模式报价。

### 5.3 信息安全

- **等保三级**已认证
- 数据加密：传输 TLS 1.3，存储 AES-256
- 密钥管理：HSM 硬件密钥模块
- 操作审计：所有运维操作全留痕，留存 ≥ 5 年
- 漏洞响应：CVSS ≥ 7 的高危漏洞 **24 小时内修复**
- **司法存证**：电子签原文 T+0 同步至司法部认可存证机构

### 5.4 性能与扩展性

| 指标 | 投标承诺 |
|---|---|
| 日均订单处理 | ≥ 50 万单 |
| 单日峰值 | ≥ 100 万单 |
| 接口 P99 响应 | ≤ 500 ms |
| 月度可用性 | ≥ 99.95% |
| 灾备 RTO | ≤ 4 小时 |
| 灾备 RPO | ≤ 15 分钟 |

### 5.5 集成能力

- **API 标准**：RESTful + Webhook + SDK（Java/Python/PHP/.NET）
- **预置对接**：金蝶、用友、SAP、Oracle、用友 NCC、管家婆
- **定制对接**：客户自有 ERP/WMS/财务系统，按 ¥3,000–¥20,000 一次性
- **数据双向同步**：实时（< 1s）/ 准实时（< 1min）/ 离线（T+1）三档可选
- **单点登录（SSO）**：支持 OIDC / SAML / CAS / 钉钉 / 企业微信

### 5.6 数据归属与可迁移性
- 所有业务数据归属采购方
- 提供全量数据导出 API + 标准化数据字典
- 合同终止后 30 天内完成全量数据交付，60 天后销毁并出具销毁证明

## 第十章 · 风险评估与应对

| 风险 | 影响 | 应对措施 |
|---|---|---|
| 客户内部 IT 配合不到位 | 实施延期 | 联合工作组制度 / 每周 PMO 会 |

## 投标策略提醒

1. **价格策略**：保留 5%–10% 让利空间，用于现场答辩或商务谈判
2. **加分项**：免费赠送货袋子权益 / ERP 试点资格 / 数据清洗服务 / 半年战略对齐会
3. **差异化**：突出"等保三级 + 司法存证 + 客户实名"三件套，对标找钢网/欧冶纯撮合
4. **底线**：私有化部署 ¥80,000 不能再降；集团版年订阅 ¥9,800 不能再降；增值服务可单点让利
5. **答辩准备**：派 1 个销售总监 + 1 个技术架构师 + 1 个客户成功，分别讲商务、技术、服务
