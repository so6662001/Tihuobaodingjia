# 从提货宝/对账宝到钢贸 ERP · 客户转化路径

> **战略定位**：提货宝/对账宝是"入场券"（小钱）；货袋子是"过路费"（中钱）；**钢贸 ERP 是"高速公路"（大钱）**。  
> **本文件目的**：让产品、销售、客户成功、市场四方对齐——**今天每一个 668 元的小微客户，明天都可能是 5–30 万年订阅的 ERP 客户**。  
> **覆盖维度**：客户分层 → 触发信号 → 转化路径 → 销售/服务/产品配合 → 财务测算  
> **生效范围**：v2 双宝订阅客户 + PAYG 客户 + 永久免费版客户

---

## 一、为什么 ERP 是终极目标

### 1.1 钢贸行业的 ERP 痛点

钢贸行业目前 ERP 状况：
- **大客户**：用金蝶/用友/SAP，**通用 ERP 强但钢贸场景适配差**——磅单、过磅、配料、调坯逻辑全靠二开
- **中型客户**：用管家婆 + Excel + 手工台账，**协同极差**
- **小微客户**：基本上没有 ERP，靠老板脑子和儿子的微信记账

**没有一家厂商真正做了"钢贸专用 ERP"——这是我们的机会。**

### 1.2 ERP 收入级别

- 客单：**¥30,000 – ¥300,000/年**（小微到集团）
- 服务期：5–10 年（极强黏性）
- 续费率：> 90%（替换成本极高）
- LTV：双宝订阅的 **20–50 倍**

### 1.3 我们的独特优势

通过提货宝/对账宝 v2 沉淀的资产，**别的 ERP 公司没有也拿不走**：

1. 已实名认证的钢贸企业 + 下游买家
2. 已跑通的全链路业务数据
3. 已对接的 e签宝 + 司法存证
4. 已建立的客户成功关系
5. 已绑定的货袋子询价习惯

**当我们的客户决定换 ERP 时，他们几乎不可能不选我们。**

## 二、客户分层与转化潜力

### 2.1 五层漏斗

```
永久免费版（无门槛）
  ↓ (升级到付费订阅)
PAYG 客户（按量付费）
  ↓ (升级到年订阅)
双宝标准/专业版（小微/中型）
  ↓ (升级到旗舰/集团版)
双宝旗舰版/集团版（大型/超大）
  ↓ (升级到 ERP)
钢贸 ERP 客户（5w–30w/年）
```

### 2.2 各层转化预期

| 来源层 | 转化到下一层比例 | 平均周期 | ERP 适配可能 |
|---|---|---|---|
| 永久免费版 → PAYG/订阅 | 15–25% | 6–12 个月 | 长期培育 |
| PAYG → 双宝订阅 | 30–40% | 3–6 个月 | 中期培育 |
| 双宝标准 → 专业 | 25% | 12 个月 | 培育中 |
| 双宝专业 → 旗舰 | 30% | 12 个月 | **重点关注** |
| 双宝旗舰 → 集团 | 40% | 12 个月 | **优先级 1** |
| 双宝旗舰/集团 → ERP | **25%**（年化）| 18–36 个月 | **核心目标** |

### 2.3 三年 ERP 客户来源测算

| 来源结构 | 预估数量 | ERP 转化率 | ERP 客户数 |

| 双宝集团版（来自超大）| 240 | 50% | 120 |

## 三、ERP 转化的"7 个触发信号"

CSM 仪表盘必须监控以下信号，触发即启动 ERP 试点对接：

| 信号 | 监控指标 | 阈值 |
|---|---|---|
| **业务规模快速增长** | 月提单数 6 个月增长 ≥ 30% | 触发 |
| **多系统集成需求** | 客户主动询问 API 对接 ERP/财务 | 触发 |
| **多分公司协同** | 新增分公司账户 ≥ 2 | 触发 |
| **复杂业态出现** | 加入跨境/期货/集采业务 | 触发 |
| **现有 ERP 不满** | 客户主动抱怨金蝶/用友/管家婆 | 触发 |
| **货袋子重度使用** | 月度撮合 GMV ≥ 1,000 万 | 触发 |
| **关键决策人变更** | CIO/CFO/老板换人 | 触发 |

> 任一触发 → CSM 24 小时内升级到"ERP 商机管理"流水线 → 产品/销售总监介入。

## 四、转化路径"五阶六触点"

### 阶段 1 · 种子期（订阅后 0–6 个月）

**目标**：让客户深度使用双宝，**沉淀业务数据**。

**触点动作**：
- CSM 30 天激活 SOP 完整执行（详见 `09`）
- 客户成功月度数据复盘
- 在客户后台**"未启用功能区"**埋点"未来 ERP 功能预览"（如调坯模块、磅单台账、库存中转）
- 季度推送"行业 ERP 趋势"邮件（不强卖，只科普）

**销售/产品配合**：
- 销售不再跟进，CSM 全权负责
- 产品悄悄收集"客户希望但目前没有"的功能反馈，沉淀为 ERP 需求池

### 阶段 2 · 触发期（6–12 个月）

**目标**：识别"7 个触发信号"，启动 ERP 沟通。

**触点动作**：
- CSM 仪表盘报警 → 触发 ERP 商机管理
- 销售总监 + 产品经理共同上门拜访
- 不卖 ERP，**先做"业务诊断"**：免费给客户出一份《业务系统差距评估报告》
- 报告里指出客户现有 ERP/Excel 的 3–5 个痛点，并展示我方未来 ERP 如何解决

**销售/产品配合**：
- 销售：开始把客户从"客户成功"流水线切到"ERP 商机"流水线
- 产品：把客户拉入"未来 ERP 共创群"，每季度做 1 次需求收集

### 阶段 3 · POC 试点期（12–18 个月）

**目标**：把客户变成 ERP 第一批种子用户。

**触点动作**：
- 提供 **3–6 个月免费 POC 试点**（旗舰/集团客户专属权益）
- 派**实施顾问**进场，做需求调研 + 小范围数据迁移
- 上线 1–2 个核心模块（如订单 + 库存），先小后大
- 每月 ROI 复盘 + 模块迭代

**销售/产品配合**：
- 销售：负责合同与商务安排，但**先不收费**
- 产品：派核心研发驻场或周对接
- 客户成功：保留服务，但与 ERP 实施分离

### 阶段 4 · 商业化签约期（18–24 个月）

**目标**：POC 转化为付费 ERP 客户。

**触点动作**：
- POC 验收 → 输出《POC 效果报告》（客户老板签字）
- 销售总监带"3 选 1"商务方案上门：
  - 选项 A：标准 ERP 订阅（¥80,000/年）
  - 选项 B：ERP + 私有化部署（¥30 万 + 5 万/年维保）
  - 选项 C：ERP + 提货宝/对账宝/货袋子全套绑定（"年订阅 + 撮合佣金减半"组合）
- 签约时**承诺老客户价格**：提货宝/对账宝/货袋子未来 5 年价格锁定 v2 水平

**销售/产品配合**：
- 销售总监主导
- 产品：提供完整产品 Demo + 案例
- 法务：准备完整合同（参考 `10-集团版与私有化投标书模板.md`）

### 阶段 5 · 深度绑定期（24 个月以后）

**目标**：客户成为长期 ERP 客户，并产生外溢价值。

**触点动作**：
- 客户成功 CSM 转为"高级客户成功（KAM）"，**1 对 1 全年陪跑**
- 半年度战略对齐会（含老板、CFO、CIO）
- 客户作为"行业灯塔案例"对外宣传（出案例视频、白皮书、媒体报道）
- 邀请客户加入"产品咨询委员会"

**销售/产品配合**：
- 销售：每年带"增值升级"包来谈（增加模块、增加用户数、增加私有化区域）
- 产品：把客户的需求做成行业级功能，复制到其他客户
- 市场：把客户故事写成标杆案例，吸引同体量客户

## 五、四类角色配合机制

### 5.1 销售（BD）

| 阶段 | 动作 |
|---|---|
| 种子期 | 不介入，由 CSM 负责 |
| 触发期 | 与产品共同上门"业务诊断" |
| POC 期 | 商务谈判，不收费 |
| 签约期 | 主导谈判与签约 |
| 绑定期 | 每年增值升级 |

**激励**：ERP 签约提成 **15%（一次性）**，年订阅 ≥ ¥80,000；续费提成 5%。

### 5.2 客户成功（CSM）

| 阶段 | 动作 |
|---|---|
| 种子期 | 主导一切 |
| 触发期 | 启动报警，移交销售 |
| POC 期 | 保留服务，与实施分离 |
| 签约期 | 协助商务 |
| 绑定期 | 转为 KAM，长期陪跑 |

**激励**：触发并最终签约 → **¥10,000/家奖金** + 客户成功分账 15%（参考 `08`）。

### 5.3 产品

| 阶段 | 动作 |
|---|---|
| 种子期 | 收集需求反馈 |
| 触发期 | 共同诊断 |
| POC 期 | 驻场或周对接 |
| 签约期 | Demo + 案例支持 |
| 绑定期 | 把客户需求做成行业功能 |

**激励**：每个 POC 转化 → 产品团队 **¥30,000 奖金池**（团队分配）。

### 5.4 实施 / 交付

| 阶段 | 动作 |
|---|---|
| POC 期 | 主导 POC 落地 |
| 签约期 | 准备实施方案 |
| 绑定期 | 持续优化与升级 |

**激励**：实施按 ERP 客单 10% 计入项目奖金池；POC 转化成功率 ≥ 50% → 团队季度奖。

## 六、ERP 产品定位（与提货宝/对账宝/货袋子的关系）

```
┌─────────────────────────────────────────────────┐
│              钢贸 ERP（公司核心利润源）              │
│  订单 │ 库存 │ 配料调坯 │ 财务 │ 应收 │ 报表        │
└──────┬──────────┬───────────┬────────────┬──────┘
       ↓          ↓           ↓            ↓
   提货宝     对账宝       货袋子      （未来）
  （执行）  （结算）    （撮合）    钢贸供应链金融
```

- **提货宝**：ERP 的"执行手脚"——线下提货合规化
- **对账宝**：ERP 的"结算大脑"——应收账款电子化
- **货袋子**：ERP 的"采购入口"——上游钢源在线化
- **未来 ERP**：把以上能力整合成完整业务大脑

**关键产品策略**：所有数据通用，**ERP 一键导入**已有 v2 客户的全部数据。这意味着客户从双宝升级 ERP 的"迁移成本 = 0"。

### 8.1 公司级 KPI

| KPI | Y1 | Y2 | Y3 |
|---|---|---|---|
| ERP 商机数（触发数）| 200 | 800 | 2,000 |
| POC 启动数 | 50 | 300 | 600 |
| ERP 签约数 | 10 | 100 | 400 |
| ERP ARR | ¥80 万 | ¥800 万 | ¥3,200 万 |
| ERP LTV 累计 | ¥240 万 | ¥3,000 万 | ¥1.5 亿+ |

### 8.2 角色级 KPI

- 销售：ERP 商机转化率 ≥ 20%
- CSM：ERP 信号发现及时率 ≥ 80%
- 产品：POC 转化率 ≥ 50%
- 实施：POC 验收通过率 ≥ 90%

### 8.3 红线

- 销售不得在客户 POC 期"突击收费"
- CSM 不得隐瞒 ERP 商机信号
- 产品/实施不得擅自承诺超出范围的定制功能
- 任何角色不得在 ERP 商机阶段把客户推向竞品

## 九、与"v2 工具"的协同节奏

```
v2 工具发布
  ↓
半年内沉淀 14,000+ 客户
  ↓
ERP 灰度内测（产品团队闭门开发）
  ↓
1 年内启动首批 50 个 POC（旗舰/集团客户优先）
  ↓
1.5 年内首批 10 个 ERP 签约
  ↓
2 年内 ERP 商业化版本发布
  ↓
3 年内 ERP ARR 突破 3,000 万
```

> **节奏铁律**：在 ERP 正式商业化之前，**所有 v2 客户活动都不得透露"ERP 即将到来"**——避免客户在试用工具时担心被绑定。

## 十、风险与对冲

| 风险 | 影响 | 对冲 |
|---|---|---|
| ERP 研发延期 | 客户失望 | POC 阶段允许"模块化"先上 2–3 个核心模块 |
| 客户流失到竞品 ERP | 高 LTV 客户丢失 | "老客户价格 + 全数据迁移"双重锁定 |
| 现有 ERP 厂商低价反扑 | 价格战 | 强化"钢贸场景独有"模块差异化（如配料调坯、磅单台账） |
| 产品功能赶不上客户需求 | 客户流失 | 季度共创会，让大客户参与定义 |
| 实施团队不足 | POC 卡壳 | 与本地实施服务商签合作，按家数分成 |
| 内部销售/CSM 抢功 | 团队失和 | 提前约定分账（销售 15% + CSM ¥10k）|
