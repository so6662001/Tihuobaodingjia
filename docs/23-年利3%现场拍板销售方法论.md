# "年利 3% 现场拍板" 销售方法论

> **战略地位**：这是 v2.2 救场版背后的**销售心理学根基**——所有定价、套餐、话术、提成最终都要回到这个原理上。  
> **本文件用途**：作为全公司销售/CSM/渠道伙伴的**入职第一课**，把"心理定价"模型从感觉变成可教、可考、可执行的方法论。  
> **覆盖对象**：BD（新人/老人）、CSM、渠道伙伴、销售总监、营销总裁  
> **核心论断**：钢贸客户是否"现场拍板"，**不取决于产品价值**，**取决于报价是否落在"老板心理拍板区间"内**

---

## 一、为什么必须叫"年利 3%"

钢贸行业的 ToB 销售有一个公开秘密：

**钢贸老板算工具账时，参考的不是"这个产品值多少钱"，是"我一年净利能拿出多少给软件"。**

| 心理区间 | 老板行为 | 销售难度 |
|---|---|---|
| ≤ 年利 1% | 老板不需思考即同意 | ⭐ 极易 |
| 年利 1–3% | **老板现场拍板的甜区** ⭐⭐⭐ | 极易 |
| 年利 3–5% | 老板说"我考虑一下"，决策周期拉到 1 个月 | ⭐⭐⭐ 中等 |
| 年利 5–10% | 老板要拉财务/合伙人开会，决策周期 1–3 个月 | ⭐⭐⭐⭐⭐ 难 |
| 年利 > 10% | 老板原则上拒绝 | ❌ 几乎不可能 |

**结论**：要让钢贸老板"听完报价不犹豫直接签"，报价必须落在 **年利 3% 以内**。

### 2.2 v2.2 套餐价 vs 3% 线

| 客群 | v2.2 套餐价 | 3% 拍板上限 | 状态 |

## 三、销售操作 SOP（4 步打法）

### 3.1 Step 1 · 问清"年利"（黄金 3 问）

> "X 总，**不冒昧地问您三件事**，我才能给您推荐最合适的方案：  
> 1. 您家**一天大概多少单**？  
> 2. **赊销比例**大概多少？  
> 3. 您家**一年下来净利大概在什么区间**？"

**话术技巧**：
- 不说"利润率"（敏感），说"净利"
- 不让客户精确（不可能）：给区间选项 → "5 万以内 / 5–30 万 / 30–100 万 / 100 万以上"
- 老板大概率会给一个**保守值**——按此计算保险

### 3.2 Step 2 · 心算 3% 拍板上限

```
客户给出年利 → × 3% = 客户心理拍板上限
```

| 客户答 | × 3% | 推荐套餐 |
|---|---|---|
| "5 万以内" | ≤ ¥1,500 | 永久免费版 + 双宝 |
| "5–30 万" | ¥1,500–9,000 | 入门包 ¥3,800 或 小微·上手包 ¥6,800 |
| "30–100 万" | ¥9,000–30,000 | 中型·标准包 ¥19,800 |
| "100–500 万" | ¥30,000–150,000 | 大型·专业包 ¥58,000 |
| "500 万以上" | ≥ ¥150,000 | 超大·集团包 ¥158,000+ |

### 3.3 Step 3 · 现场算账（必须当面）

> "您一年净利大概 _____ 万。  
> 我推荐您 _____ 套餐，年费 ¥_____。  
> 算下来一年只占您净利的 **_____ %**——比您一个销售年终奖还少。  
>  
> 您看这个数，能不能现场就定？"

### 3.4 Step 4 · 临门一脚（消灭"考虑一下"）

> "X 总，您要是觉得 _____ 还是有点高，咱有 ¥3,800 入门包；要是觉得合适，今天定我帮您申请 3 个月增值包加赠。  
> 您今天不定，我也理解，但**每一天您账上躺着的应收账款，都在烧利息** —— 您算一下，这个利息够买多少年套餐？"

## 四、为什么是 3%，不是 5%/10%

### 4.1 行业数据（必背）

- **3%** = 老板可以**完全凭直觉**决策，财务不参与
- **5%** = 老板要**算一下账**，财务通常会参与
- **10%** = 老板必须**召开决策会**，引入合伙人/股东讨论

### 4.2 钢贸特殊性

钢贸老板的"3% 阈值"比一般行业更低，因为：

| 原因 | 解释 |
|---|---|
| **毛利极薄** | 0.5–1.5% 的钢贸毛利，老板对每 1% 都极敏感 |
| **决策极快** | 老板兼销售兼司机，没时间开会，"3% 内拍" 是行业习惯 |
| **不信任 SaaS** | 60% ERP 项目失败，老板对工具支出本能怀疑 |
| **资金优先级低** | 资金第一优先级是采购钢源、第二是仓库、第三才是软件 |

### 4.3 实战印证

- 2025 年 WMS 由 ¥10,000 → ¥15,000 失败 → **15,000 占中型客户年利 60 万的 2.5%（仍在 3% 内）**，但累计若买 10 个用户就是 25%！客户算的是**总投入占年利比**，不是单价比
- v2.1 中型套餐 ¥45,800 = 占 60 万年利的 **7.6%** → 大部分客户拒绝
- v2.2 中型套餐 ¥19,800 = 占 **3.3%** → 现场拍板率显著上升

## 五、SCRM 系统必备字段（数据沉淀）

为了让"年利 3%" 不只是个口号，CRM 中每个客户必须记录：

| 字段 | 来源 | 用途 |
|---|---|---|
| `est_annual_profit_range` | 销售首次接触时填 | 计算拍板上限 |
| `recommended_package_tier` | 系统自动按 3% 推荐 | 销售一键推送 |
| `actual_quoted_amount` | 销售实际报价 | 复盘是否在拍板区 |
| `decision_made_at` | 客户决定时间 | 复盘"现场拍板"比例 |
| `lost_reason` | 客户拒绝原因 | 异常报价导致流失需复盘 |

### 5.1 销售日报必含

- 今天接触 N 家客户
- 其中报价在拍板区（≤ 3% 年利）M 家
- 现场拍板 K 家
- **拍板率 K/M**（核心指标）

### 5.2 销售排行（按"拍板率"，而非"金额"）

- TOP 5 拍板率销售 → 月度表彰
- BOTTOM 销售 → 重点辅导（不是开除，是重新培训"年利 3%"原理）

## 六、销售老板异议处理（实战题库）

### Q1：客户不告诉我年利怎么办？

> 用代理数据：  
> 日单量 × 平均吨价 × 365 × 行业平均毛利率 0.8% = 估算年净利  
> 例：30 单 × 4,000 元/吨 × 25 吨 × 365 × 0.8% = 87.6 万 → 但小微毛利更低，按 50% 折扣 ≈ 43 万  
> 取保守值 30 万 → × 3% = ¥9,000 → 推 中型·标准包 ¥19,800（稍超 3%，但有合理性）

### Q2：客户年利特别高（如年利 1 亿），按 3% 是 ¥300 万 → 我们卖不了那么贵啊？

> 上限封顶：年利 × 3% 是"上限"，不是"目标"。  
> 超大客群我们最高套餐 ¥158,000，已经满足客户。  
> 客户多花的钱可以推 OCR、3 年存证、API 对接、私有化部署等增值——把客单做高，但**不要超过总投入年利 5%**

### Q3：客户算自己年利不对，导致推错套餐怎么办？

> 不害怕。第一年按客户说的来。  
> 30 天复盘时让数据说话："您家月度业务量 ____，对应应该是 _____ 档"，下年自然升档。  
> **首年宁可推小不推大** —— 客户用顺了，明年自己加单。

### Q4：客户说"你们价格便宜没好货"怎么办？

> "X 总，我们就是凭'**让您看得起得起**'立足。年利 3% 是您能现场拍板的线，超过这条线您必须找财务、找合伙人——决策周期 1 个月，您家应收账款已经多烧 5 万利息。  
> 我们的产品价值大概是售价的 5–10 倍，**剩下的价值留给您下一笔升级再变现**。"

### Q5：营销总裁说"那我们利润太薄了！"

> 不是利润薄，是**LTV 长**。  
> 首年 ¥19,800 中型客户 → 5 年累计 ¥99,000 + 货袋子佣金 ¥150,000 + 增值 ¥30,000 = **5 年 LTV ≈ ¥279,000**  
> 首年毛利 37% × ¥19,800 = ¥7,326；但 5 年累计毛利 ≈ ¥130,000  
> **"年利 3% 入门 → 5 年留住 → 长 LTV"** 这才是 SaaS 模型

## 七、训练与考核

### 7.1 新人入职必学

- 阅读本文件 + 通过笔试（10 题，80 分及格）
- 实操 3 个模拟客户案例（销售总监打分）
- 跟岗 5 次老销售上门 → 至少 2 次能独立"问年利 → 推套餐"

### 7.2 老销售季度复训

- 数据复盘：上季"现场拍板率"
- 案例讨论：拍板失败客户的"年利 3%"分析
- 升级训练：如何用"OCR / 3 年存证 / 多年付"提升客单 ≤ 总投入年利 5%

### 7.3 销售总监考核

- 团队整体"现场拍板率"≥ 50%
- 团队"问年利覆盖率"≥ 90%（90% 的客户必须有年利估算字段）
- 团队"推 v2.2 套餐占比"≥ 70%（其余是 v2.1 长老客户）

## 八、与"双宝抵扣 + 多年付折扣"的联动

### 8.1 把 5% 的客户拉进 3% 区间

如果客户实际报价超 3% 但又在 5% 内，用以下"组合工具"让他**感觉**回到 3%：

| 客户实际 | 推套餐 | 实际占比 | 组合工具 | 感知占比 |
|---|---|---|---|---|
| 年利 30 万 | 中型 ¥19,800 | 6.6% | + 双宝抵扣 2 年 ¥2,936 | 5.6% |
| 同上 | + 3 年付 85 折 = 一年 ¥16,830 | | 同上 + 抵扣 | **4.6%** |
| 同上 | 仍在 5% → 转入门包 ¥3,800 | | | **1.3% ⭐ 现场拍板** |

> 关键：**先报价 → 客户犹豫 → 用工具组合拉回 3% → 客户拍板**

### 8.2 让客户主动加购增值（拉客单到 5% 但不犯红线）

- 中型客户买完套餐 → 主动推 3 年存证 ¥3,000 = 占年利 3.8%
- 大型客户 → 主动推 OCR + API = 占年利 4.5%
- 把"加购"做在客户已签套餐之后，**不动套餐价**，但 ARPU 拉升

## 十、案例库（5 个真实成功案例，新人培训用）

### Case 1（小微·拍板）
- 客户：江苏某钢贸，年利 12 万
- 标准报价：小微·上手包 ¥6,800（5.6%，超 3%）
- 实际打法：先推**入门包 ¥3,800（3.2%）**，老板 30 秒拍板
- 结果：6 个月后升级到上手包 ¥6,800

### Case 2（中型·组合拉低）
- 客户：上海某中型，年利 55 万
- 标准报价：中型·标准包 ¥19,800（3.6%）
- 老板犹豫 → 销售加"3 年付 85 折"= ¥16,830（3.1%）
- 结果：现场签 3 年付，锁 LTV

### Case 3（大型·年利问对了）
- 客户：山东某大型，老板初报"年利 100 万"
- 销售算 3% = ¥30,000，推中型套餐
- 客户用 3 个月后业务量直接超中型上限
- 老板复盘：实际年利 250 万
- 后续：升级到大型套餐 ¥58,000（占真实年利 2.3%）

### Case 4（超大·客单做高）
- 客户：杭州某超大，年利 1,500 万
- 套餐 ¥158,000 = 1.05%
- 销售主动加：私有化 ¥80,000 + OCR ¥30,000 + 3 年存证 ¥50,000
- 总单 ¥318,000 = 2.1%，仍在 3% 内，现场拍板

### Case 5（失败案例 · 反思）
- 客户：广东某中型，年利 40 万
- 销售自作主张报"大型·专业包 ¥58,000"（14.5%）
- 客户当场翻脸："你拿我当冤大头！"
- 后续：销售总监介入，重新报中型套餐，客户勉强签，但 NPS 极差，第二年没续约
- 教训：**永远不要超 5% 给客户报价**
