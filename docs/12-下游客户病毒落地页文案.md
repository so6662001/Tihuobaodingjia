# 下游客户病毒落地页文案

> **战略定位**：v2 战略的"病毒系数 K"的真正发生地——每一笔提货宝/对账宝触达的下游买家，都要在这一页完成"看见 → 心动 → 注册 → 绑定推荐人 → 沉淀为下一个 14,000 家客户的来源"。  
> **本文件用途**：H5 / 小程序 / 微信内嵌的下游签收页 + 注册引导页文案与交互  
> **覆盖路径**：4 种触达入口、6 种文案变体、3 个关键 CTA、1 套实名注册流程、1 套老带新绑定机制  
> **关键指标（KPI）**：签收页"开通注册"点击率 ≥ 8%，注册转化率 ≥ 35%，30 天激活率 ≥ 25%

---

## 一、为什么这一页决定 v2 战略成败

钢贸链路上的下游买家，是 v2 最大的免费流量池：

- 每位订阅客户（小微）平均触达 20–50 个下游买家
- 每位中型客户触达 50–100 个
- 每位旗舰客户触达 150–300 个
- **14,040 家首年付费客户 → 约 70 万下游买家被强制触达**

**这 70 万下游买家，是下一轮裂变的种子，是货袋子的询价流量，是 ERP 的潜在客户。**

如果这一页做不好，v2 战略就是"半截工程"——花了钱买流量，却没接住。

## 七、注册流程（关键转化漏斗）

### 7.1 最少步骤注册（强烈建议 ≤ 3 步）

```
Step 1 · 手机号 + 验证码（已带入下游签字时手机号 → 一键确认）
   ↓
Step 2 · 企业名称 + 营业执照（拍照上传 OCR 自动识别）
   ↓
Step 3 · 选择套餐
   - 永久免费版（默认）
   - 双宝小微 ¥668（折扣价 ¥618，因为带推荐人）
   ↓
完成 → 自动绑定推荐人 → 跳转后台
```

### 7.2 减少摩擦的 5 个细节

1. **手机号一键带入**：用户在签字时已留手机号，注册无需再输
2. **OCR 一键识别**：营业执照拍照 / 上传 PDF 即可，无需手填
3. **微信授权登录**：可选用微信扫一扫快速登录
4. **推荐人自动带入**：URL 参数 `?inviter=____` 自动绑定，**永久归属**
5. **不强制套餐选择**：默认永久免费版，用户随时升级

## 十、风险控制

### 10.1 防止"被裂变"成骚扰

- 短信每 24 小时不超过 1 条
- 用户可随时回 TD 退订
- 退订后永不再触达

### 10.2 防止虚假注册

- 同手机号 / 同营业执照 / 同 IP 只能绑定 1 个企业账户
- OCR 自动比对营业执照真伪
- 注册 30 天内无任何活跃 → 推荐奖励暂缓发放

### 10.3 防止"自导自演"刷推荐

- 推荐人 ↔ 被推荐人手机号相似度检测
- 同地址 / 同股东 / 同实控人 → 不计裂变奖励
- 反舞弊抽查比例 ≥ 5%/月
