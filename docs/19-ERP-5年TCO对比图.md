# ERP 5 年 TCO 对比图（销售视觉化武器）

> **战略地位**：销售现场被问"金蝶比你们便宜"时**唯一能反败为胜的工具**。  
> **本文件用途**：把"金蝶/用友/SAP 看起来便宜"打回原形——通过 5 年 **TCO（总持有成本）** 算账，让客户自己看到"贵的反而是便宜的"。  
> **打印形态**：A3 横版彩图（PDF 可导出 A4 黑白），销售随身带；同时输出 H5 互动版（客户自填数据，实时计算）。  
> **法律提示**：所有竞品价格基于公开渠道（如金蝶/用友官网、行业报价单），上线前由市场+法务复审一次

---

## 一、为什么必须用 TCO 而不是"价格表"

钢贸老板看价格只看"今年要付多少钱"，但 ERP 是 5 年合作产品。所有竞品的"低价"都是首年陷阱：

| 隐性成本 | 一般客户看不到 | TCO 一定要算进去 |
|---|---|---|
| 二次开发费 | 钢贸磅单 / 配料 / 调坯 → 通用 ERP 必须二开 | ✅ |
| 集成对接费 | 与下游电子签、与提货宝/对账宝集成 | ✅ |
| 实施服务费 | 通用 ERP 一般 ¥10–50 万 | ✅ |
| 培训费 | 钢贸场景特殊，培训费高 | ✅ |
| 年服务费 | 10–20% 软件原价 | ✅ |
| 升级费 | 每年大版本升级需买 | ✅ |
| 硬件 / IDC | 私有部署需自建机房 | ✅ |
| 内部 IT 人力 | 全职 ERP 运维至少 1 人 | ✅ |
| 失败重做成本 | 60% ERP 项目失败 → 重新选型 | ✅（按 50% 概率折算）|

## 四、销售现场使用方法

### 4.1 三步法

```
Step 1：问客户三件事 → 用户数、仓库数、目前在用什么系统
Step 2：用本卡找到匹配的 TCO 表
Step 3：让客户自己读出"5 年总成本差多少"
```

### 4.2 关键话术

> "X 总，您看这张表——咱不算今年，咱算 5 年。  
> 您要是选金蝶/用友：5 年下来 _____ 万。  
> 您要是选我们：5 年下来 _____ 万。  
> **差额 _____ 万，相当于您 _____ 个销售一年的总提成。**  
> 您这一笔决定，不只是省 _____ 万，是给您团队多发 _____ 个销售的工资。"

### 4.3 异议处理

| 客户说 | 回应 |
|---|---|
| "你们这数据真实吗？" | "金蝶/用友官网价格就这样，二开费用是行业普遍报价。我们提供书面承诺，5 年总成本超过 ¥99,000 退全款。" |
| "我们自己有 IT，不算运维。" | "好，那也至少算工资+社保 ¥10万/年 × 5 = ¥50 万——这是您内部成本，省不掉。" |
| "我们不需要 WMS。" | "现在不需要，5 年内一定会要——钢贸合规越来越严。我们套餐含 WMS，您升级不花钱。" |
| "二开我们能自己做。" | "您自己做要请 1 个 Java + 1 个 ERP 实施，2 人 1 年 ¥40 万。" |

## 六、印制规范（A3 销售卡）

- 尺寸：A3 横版（420 × 297 mm）
- 双面：正面 TCO 大表 + 视觉条图 / 反面"三步法 + 异议处理"
- 主色：黑金 + 红字突出"+¥XX 万"
- 字号 ≥ 16pt（保证客户老板眼睛能看清）
- 数据每季度由销售运营更新一次
- 旧版必须回收，避免客户拿到过期数据

---

## 七、铁律

1. **数据来源必须可查**：所有竞品价格附公开链接，避免被客户驳"假数据"
2. **不主动贬低竞品**：让客户自己读数字得结论
3. **退款承诺要敢写**：5 年 TCO 写进合同附件，超出退全款 → 这是我方差异化的最大武器
4. **每年更新**：竞品涨价/降价、内部 IT 成本变化 → 季度更新版本号
