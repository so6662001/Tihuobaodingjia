## 三、6 大竞品深度拆解

### C1 · 找钢网

**核心定位**：钢贸撮合平台（钢厂 → 贸易商 → 终端）+ 物流 + 部分仓储

**主要产品**：
- 找钢网交易撮合
- 胖猫物流 / 物流单 SaaS
- 部分财务/票据服务

**优势**：
- 流量大、品牌响
- 钢厂资源密集，撮合效率高
- 免费工具吸引中小贸易商

**劣势**：
- 撮合费率 0.5–1%，被中小贸易商视为"中间商赚差价"
- 工具能力弱：缺乏"提货 8 节点全链路电子签"
- 缺乏欠款证据链与对账电子化
- 客户实名档案弱（多数客户是匿名 ID）

**我们如何反差**：
- "撮合我们也做，**佣金只有 0.10–0.30%**（找钢网的 1/3–1/5）"
- "您卖给客户的部分，可以用我们的提货宝 + 对账宝把每一笔做成可起诉证据"
- "找钢网帮您找上游，我们帮您管下游——两边都做，您的护城河才完整"

**销售话术**：
> "X 总，您肯定知道找钢网。它解决的是您找钢厂的问题，我们解决的是您管客户的问题。我们没有任何冲突，反而是互补。而且我们的撮合费率是它的 1/3—1/5，您可以两边都用。"

---

### C2 · 欧冶云商（宝武集团旗下）

**核心定位**：央企背景的钢贸 + 物流 + 供应链金融

**主要产品**：
- 欧冶产业互联网平台
- 欧冶金服（供应链金融）
- 欧冶物链（物流）
- 欧冶云仓

**优势**：
- 央企背景 + 宝武钢厂直营
- 强大的金融工具与征信能力
- 央/国企客户首选

**劣势**：
- 价格高，**起步价 ¥10 万级**，小微/中型贸易商负担不起
- 决策周期长，上线复杂
- 中立性受质疑（央企色彩，非宝武钢厂的贸易商不愿绑定）
- 偏 B2B 业务流，下游小客户体验差

**我们如何反差**：
- "我们是中立、跨钢厂的工具"——客户用我们不必担心被绑死在某一家钢厂体系
- "欧冶是给上市/央企的，我们是给所有钢贸的"——客单 ¥668 起 vs ¥10 万起
- "我们上线 60 秒，欧冶上线 60 天"

**销售话术**：
> "欧冶是宝武家的，您要是只做宝武系，欧冶很合适。但您是独立钢贸，您的客户来自多个钢厂，您需要一个中立的、各方都能接受的工具。这就是我们。"

---

### C3 · 钉钉电子签 + e签宝 / 法大大

**核心定位**：通用企业电子签 SaaS

**主要产品**：
- 钉钉电子签（按月套餐）
- e签宝（独立 + 嵌入式 SaaS）
- 法大大（独立 + API）

**优势**：
- 价格极低（按签字 ¥0.1–0.3/次）
- 法律效力被广泛认可
- 集成生态强（钉钉 / 飞书 / 微信）

**劣势**：
- 通用工具，**不懂钢贸业务**：磅单 / 装车单 / 仓库出门时间 / 派车单等钢贸特有节点全部需要客户自己设计
- 只解决"签字"环节，**不解决全链路通知、催收、对账、客户档案**
- 客户需要自行搭建业务流程，**实施复杂度反而高**

**我们如何反差**：
- "电子签只是 8 个钢贸节点中的 1 个，我们把 8 个全部包了"
- "我们底层也是 e签宝（合作伙伴），并且全部钢贸场景已经预置好了——您拿来就能用"
- "您用通用电子签自己搭，IT 成本至少 ¥10 万；用我们，¥668 一年全有"

**销售话术**：
> "钉钉/e签宝/法大大都是好工具，我们和 e签宝是底层合作伙伴。但您是钢贸老板，您要的不是签字这个动作，而是整个'8 节点全链路'。我们已经把这件事做完了，您拿来就能用。"

---

### C4 · 管家婆 / 用友 T+ / 金蝶 KIS

**核心定位**：中小企业通用 ERP

**主要产品**：
- 管家婆 · 软件年付 ¥3,000–10,000
- 用友 T+ Cloud / 畅捷通
- 金蝶 KIS / 精斗云

**优势**：
- 老牌、口碑稳、培训资源多
- 财务/库存/进销存功能完整
- 客户基数大

**劣势**：
- 通用 ERP，**钢贸特殊场景需大量二次开发**（磅单、配料、调坯等）
- 电子签 / 客户实名 / 自动催收等几乎为零
- 上线周期长（2–3 个月），中小客户上不了
- **价格比我们贵 5–10 倍**，但功能未必更适配

**我们如何反差**：
- "ERP 是大脑，我们是手脚——手脚先用上，您再决定要不要换大脑"
- "您的 ERP 可以保留，我们和 ERP API 对接（¥3,000–20,000）"
- "未来我们也会出钢贸专用 ERP，到时候您可以无缝迁移"

**销售话术**：
> "您家如果已经在用管家婆，我们完全不影响，我们和它能 API 对接。但您一定发现了：管家婆做对账、做催收、做电子签都不顺手——这些我们专门做。¥668 + 您现有 ERP，比再花 ¥3 万换 ERP 划算多了。"

---

### C5 · 金蝶云·星空 / SAP / 用友 NCC

**核心定位**：大型集团 ERP

**主要产品**：
- 金蝶云·星空 / 苍穹（年订阅 ¥20 万–¥200 万）
- SAP S/4HANA（项目级，几千万）
- 用友 NCC

**优势**：
- 集团级标准化能力
- 财务 / 供应链 / HR 一体
- 行业大客户标配

**劣势**：
- **天价**，钢贸利润 0.5–1%，回本无望
- 不懂钢贸特殊场景，二开费用动辄百万
- 上线 6–18 个月，决策周期巨长
- 与下游小客户的电子签 / 自动催收完全没有

**我们如何反差**：
- "您可以保留金蝶/SAP 做财务和总账，我们做提货 + 对账 + 撮合三件事"
- "我们和金蝶/SAP API 对接（¥3,000–20,000）"
- "未来我们出钢贸 ERP，您可以选择只换钢贸业务部分，保留集团财务部分"

**销售话术**：
> "X 总，您集团用 SAP/金蝶很对——那是集团的大脑。但 SAP 不懂磅单、不懂调坯、不懂电子签到客户手里。我们就是 SAP 的'钢贸手脚'。我们对接您的 SAP，让 SAP 看到的是干净结构化的钢贸数据。"

### C6 · 本地 ERP 定制商

**核心定位**：区域钢贸/物流园定制软件

**典型形态**：
- 某地某公司，10–50 人规模
- 单客户定制，按项目报价 ¥10–100 万
- 强关系销售

**优势**：
- 强本地关系
- 老板对老板关系
- 能做高度定制

**劣势**：
- **不可持续升级**：开发完就甩手，bug 不修、需求不接
- 没有行业生态，永远是孤岛
- 价格虚高，没有标准化
- 容易随定制商团队解散而崩盘

**我们如何反差**：
- "定制商把您绑死在他身上；我们是标准化产品 + 行业生态，您随时可以离开但您不会想离开"
- "定制商一年 1 个版本（如果还在），我们一个季度 4 个版本"
- "定制商垮了您没人管，我们垮了您的数据在国家存证中心独立保管"

**销售话术**：
> "本地定制商是熟人，关系到位很方便。但您仔细想：他给您做了一套系统，5 年后他公司还在不在？版本还能升级吗？我们是标准产品 + 行业生态，未来 10 年我们都在，您的数据也都在。"

## 四、按客群差异化打法

### 4.1 小微客户：对比 C1 / C3

> 这类客户的"竞品"主要是"什么都不用"或"找钢网/钉钉电子签"。

**关键打法**：
- 强调"永久免费版"先用
- 对比找钢网撮合费率（我们 1/3）
- 对比钉钉电子签的"自己搭"成本

**话术**：
> "您现在用找钢网撮合，但客户那边的发货确认、催收都还是微信群一笔一笔追，对吧？我们补的就是这一段。永久免费版每月 100 单，您先用一个月试试。"

### 4.2 中型客户：对比 C4

> 这类客户的"竞品"主要是用友 T+ / 管家婆 / Excel + 微信。

**关键打法**：
- 不替代 ERP，API 对接
- 强调"30 天激活 + ROI 复盘"

**话术**：
> "您家用着 T+ 我知道，我们专门和 T+ 做了 API 对接，不冲突。您只需要把'对客户的电子签'和'自动催收'这两件事交给我们，T+ 该干嘛干嘛。"

### 4.3 大型客户：对比 C5 / C6

> 这类客户的"竞品"主要是金蝶 / SAP / 本地定制商。

**关键打法**：
- 不替代 ERP，做"钢贸专用手脚"
- 突出"标准化 + 长期升级"反差本地定制
- 强调"私有化部署可选"

**话术**：
> "X 总，您家用 SAP 做集团财务很合适。我们和 SAP 是互补：您 SAP 看不到下游客户每一次提货、签字、对账，我们专门做这一段。¥3,980 + 一次性 API 对接 ¥10,000，相当于给您 SAP 装一对真懂钢贸的手脚。"

### 4.4 超大集团：对比 C2 / C5

> 这类客户的"竞品"主要是欧冶云商 / SAP / 自研。

**关键打法**：
- 中立性（不绑死任何钢厂）
- 私有化部署 + 等保三级
- 长期生态绑定（货袋子 + ERP）

**话术**：
> "欧冶是央企体系，您用着可能会担心数据被宝武看到。我们是独立中立的，所有数据归您所有。私有化部署 ¥80,000 一次性，您数据在自己 IDC，央企/上市公司审计完全过得了。"

## 六、SWOT 矩阵（高管视角）

## 七、客户最常问的 8 个对比问题（销售必背）

### Q1：你们和找钢网什么关系？
> 找钢网是上游撮合（找钢厂），我们是下游管理（管客户）。两边互补，您可以同时用。撮合方面我们也有货袋子，佣金只有它的 1/3。

### Q2：你们和钉钉电子签比，便宜还功能多，是不是夸大？
> 我们底层就是 e签宝（钉钉电子签的姐妹产品）。我们只是把"电子签 + 钢贸 8 节点"打包了。您用钉钉电子签是自己搭，搭完发现 IT 成本比我们高。

### Q3：我用着金蝶/SAP，还需要你们吗？
> 完全需要。SAP/金蝶做总账与财务，做不了"对下游客户的电子签 + 自动催收"。我们就是 SAP/金蝶的"钢贸手脚"。API 对接 ¥3,000–20,000。

### Q4：我用着管家婆/用友 T+，能对接吗？
> 能，我们有标准 API。您管家婆该用还用，我们补"对下游电子化"这一段。

### Q5：你们和欧冶云商比？
> 欧冶是宝武家的，您是非宝武系钢贸或独立钢贸，用欧冶不太合适。我们中立。您下游什么钢厂的客户都能接。

### Q6：本地定制商关系好，价格也能谈，为什么选你们？
> 关系好是真的，但定制商垮了您系统也垮了。我们标准产品，5 年后我们还在，10 年后我们还在；您的数据在国家电子认证服务中心独立存证，永远不会丢。

### Q7：你们这么便宜，是不是有什么坑？
> 没有。我们工具几乎平本，赚的是您未来在货袋子撮合时的薄佣金。这模式叫"前端引流后端变现"，跟微信、钉钉是一套逻辑。

### Q8：未来你们会涨价吗？
> v2 价格 6 个月内官方承诺不涨。即便未来涨价，老客户永远锁定老价。这是写进合同的。
