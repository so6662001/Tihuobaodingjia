## K · 常见问题 FAQ（v2 重点回应"为什么便宜"）

**Q1：价格为什么比同行便宜这么多？是不是有什么坑？**  
A：没有坑。原因有二：① 电子签和短信的真实成本极低（首次客户 1.3 元，每签 0.01 元）；② 我们的盈利模型不靠工具订阅，而是您未来在"货袋子"平台撮合钢厂询价/采购时，我们抽取很薄的佣金。**工具我们让利，您用得越好，我们才赚得越多。**

**Q2：我们已经有 ERP 了，还需要这个吗？**  
A：提货宝/对账宝不是替代您的 ERP，而是给您 ERP 加上"前手 + 后手"。我们支持主流 ERP 一键 API 对接，对接费 ¥3,000 起。

**Q3：我们客户不太会用电子签，怎么办？**  
A：92% 的下游客户首次即可完成微信电子签。剩余 8% 我们提供"纸签兜底模板"，可与电子签并行运行 3 个月做过渡。

**Q4：3 年以上的证据怎么收费？**  
A：默认 3 年免费存档；超过 3 年部分按 **¥5/条/年** 或 ¥80/GB/年 续存，您可按需选择。

**Q5：免费版有什么坑吗？**  
A：没有。免费版永久免费，仅有月单量上限和短信条数上限。超过上限时，您可选择按量加购（PAYG）或升级套餐。

**Q6：数据是不是只有我能看？**  
A：是。所有数据归您企业所有，平台仅做托管。我们提供数据导出 API，您随时可以全量带走。

**Q7：跑路了怎么办？**  
A：所有电子签原文均已在司法部认可的第三方存证机构（国家电子认证服务中心等）独立存证。即便我们公司不存在了，您仍可调取所有证据用于司法举证。

**Q8：支持开发票吗？**  
A：支持 6% 增值税专用发票，年付一次性开具。

**Q9：v2 价格之后会不会涨价？**  
A：**官方承诺 v2 价格 6 个月内不变**。已签客户次年续费**价格锁定**，不受涨价影响。
