## K · 常见问题 FAQ

**Q1：我们已经有 ERP 了，还需要这个吗？**  
A：提货宝/对账宝不是替代您的 ERP，而是给您 ERP 加上"前手 + 后手"——前端提货全链路签字，后端对账自动催收。我们支持主流 ERP 一键 API 对接。

**Q2：我们客户不太会用电子签，怎么办？**  
A：92% 的下游客户首次即可完成微信电子签。剩余 8% 我们提供"纸签兜底模板"，可与电子签并行运行 3 个月做过渡。

**Q3：3 年以上的证据怎么收费？**  
A：默认 3 年免费存档；超过 3 年部分按 ¥10/条/年 或 ¥100/GB/年 续存，您可按需选择。

**Q4：免费版有什么坑吗？**  
A：没有。免费版永久免费，仅有月单量上限和短信条数上限。超过上限时，您可选择按量加购或升级套餐。

**Q5：数据是不是只有我能看？**  
A：是。所有数据归您企业所有，平台仅做托管。我们提供数据导出 API，您随时可以全量带走。

**Q6：跑路了怎么办？**  
A：所有电子签原文均已在司法部认可的第三方存证机构（国家电子认证服务中心等）独立存证。即便我们公司不存在了，您仍可调取所有证据用于司法举证。

**Q7：支持开发票吗？**  
A：支持 6% 增值税专用发票，年付一次性开具。
