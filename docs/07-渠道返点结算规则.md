# 提货宝 & 对账宝 · 渠道返点结算规则（v2 · 财务可直接执行版）

> **生效范围**：与公司签约的所有渠道伙伴（园区/商会/钢厂/独立 BD/代理商），以及"老带新"的客户自发推荐人  
> **生效日期**：v2 价格政策同步生效之日起  
> **有效期**：6 个自然月，期满前 30 天评估是否调整  
> **业务归口**：渠道部 / 销售运营部  
> **财务归口**：财务部 · 应付账款组  
> **审批与对账系统**：CRM + 财务 ERP + 渠道伙伴门户（三系统数据互通）

---

## 一、渠道伙伴分类与基础认定

### 1.1 四类渠道

| 类型 | 定义 | 准入门槛 |
|---|---|---|
| **A · 战略伙伴** | 钢贸物流园、行业协会、头部钢厂、上市钢贸集团 | 签订年度独家/优先合作协议；承诺年带客 ≥ 100 家 |
| **B · 区域代理** | 区域内独立销售机构、行业 KOL、地区 ERP 服务商 | 缴纳 ¥10,000 保证金；年带客 ≥ 30 家 |
| **C · 独立 BD** | 个人或小型团队，挂靠公司销售 | 在线申请通过即可；无最低带客 |
| **D · 老带新客户** | 已购付费客户推荐其他企业 | 自动激活，无须申请 |

### 1.2 准入与备案

- 渠道伙伴须签署《渠道合作协议》（含保密、反舞弊、独家/非独家界定），财务备案。
- 每个伙伴分配唯一**渠道码（Partner ID）**；推荐链接、二维码、邀请码均带 Partner ID。
- **Partner ID 唯一归属客户**：客户首次注册时携带的 Partner ID 永久绑定，**后续续费、增值购买均按此归属计算返点**（除非客户主动书面变更）。

## 二、返点计算口径

### 2.1 总原则

1. **激活提点 + 续费提点 + 增值提点** 三层结构
2. **现金返还**（非货品、非积分），按月对账、按月结算
3. **以客户实付金额为基数**（不含税、不含发票邮寄费）
4. **不重复计算**：同一笔订单不得同时计入"销售提成 + 渠道返点"，由 CRM 在订单归属时自动判定

### 2.2 四类伙伴的返点结构

| 客群 | A 战略伙伴 | B 区域代理 | C 独立 BD | D 老带新客户 |
|---|---|---|---|---|
| **激活提点**（一次性，首次付费时计提） | **¥200/家** + 首笔订单金额 25% | 首笔订单 30% | 首笔订单 25% | **¥50–200/家**（按客群） |
| **续费提点**（每续费一次） | 续费金额 8% | 续费金额 5% | 续费金额 3% | 0 |
| **增值提点**（OCR/存证/API 等增值订单）| 增值金额 15% | 增值金额 10% | 增值金额 8% | 0 |
| **裂变奖励**（带新客户的客户再带新）| —  | —  | —  | 每带 3 家升档；10 家下年免费；30 家直升集团版 |

### 2.3 D 类（老带新）的"¥50–200/家"按客群分档

| 被推荐客户购买 | 推荐人获得抵扣 |
|---|---|
| 小微双宝 ¥668 | **¥50** |
| 中型双宝 ¥1,468 | **¥100** |
| 大型双宝 ¥3,980 | **¥150** |
| 集团双宝 ¥10,800 起 | **¥200** |
| PAYG 客户（连续 3 个月有计费）| **¥50** |

> 注：D 类返点以"年费抵扣券"形式发放，非现金；若推荐人为 PAYG 客户，可冲抵未来账单。

### 2.4 A 类战略伙伴的"额外大客户激活奖"

| 推荐客户类型 | 额外奖金 |
|---|---|
| 集团版客户（年订阅 ≥ ¥10,800）| **¥1,000/家** |
| 私有化部署客户（¥80,000+）| **签约金额 5%，封顶 ¥10,000** |
| ERP POC 转化客户 | **¥3,000/家**（POC 完成验收后发放）|

## 三、计算示例（必看 · 财务核对参考）

### 例 1：B 类代理带来 1 家小微双宝客户

- 客户首次付款：¥668
- 激活提点 = 668 × 30% = **¥200.4**
- 财务月结发放：¥200.4

### 例 2：A 类战略伙伴带来 1 家集团双宝 + 后续买 API 对接

- 集团双宝首付：¥10,800
- 激活提点 = ¥200 + 10,800 × 25% = ¥200 + ¥2,700 = **¥2,900**
- 集团客户大客户激活奖：**+¥1,000**
- 半年后客户购买 API 对接 ¥15,000
- 增值提点 = 15,000 × 15% = **¥2,250**
- 累计返点：**¥6,150**

### 例 3：D 类老带新 · 中型客户推荐 5 家小微 + 3 家中型

- 5 × ¥50 = ¥250
- 3 × ¥100 = ¥300
- 阶梯触发：累计 8 家，未达 10 家
- 当前返点 = **¥550 年费抵扣**（用于推荐人本人续费时抵扣）

### 例 4：C 类独立 BD 带 1 家中型客户，客户次年续费 + 加购 OCR

- 首付 ¥1,468，激活提点 = 1,468 × 25% = **¥367**
- 次年续费 ¥1,468，续费提点 = 1,468 × 3% = **¥44**
- 加购 OCR 用量 ¥2,000，增值提点 = 2,000 × 8% = **¥160**
- 两年累计：**¥571**

## 四、对账与结算流程

### 4.1 流程图

```
T-Day（计费日，每月 1 日）
  ↓
T+3：CRM 自动生成各伙伴月度对账单（含明细）
  ↓
T+5：伙伴在渠道门户中确认/异议
       └─ 异议 → T+10 内由销售运营部复核
  ↓
T+10：对账单冻结（无异议或异议处理完毕）
  ↓
T+15：财务发起付款（C/D 类）/ 财务提交对公付款（A/B 类）
  ↓
T+20：完成支付，伙伴收到款项 + 电子付款凭证
  ↓
T+25：财务月度归档；销售运营部按伙伴排名出"月度榜单"
```

### 4.2 关键时间窗（财务可直接抄写为 SOP）

| 节点 | 节点动作 | 责任部门 |
|---|---|---|
| 每月 1 日 00:00 | 上月数据冻结，生成对账单 | 系统自动 |
| 每月 3 日 18:00 | 推送对账单至伙伴门户与邮箱 | 销售运营部 |
| 每月 5 日 24:00 | 伙伴异议提交截止 | 渠道伙伴 |
| 每月 10 日 18:00 | 异议处理完毕，对账单冻结 | 销售运营部 |
| 每月 15 日 | 财务发起付款 | 财务部 |
| 每月 20 日 24:00 | 全部支付到账 | 财务部 |
| 每月 25 日 | 月度归档 + 榜单发布 | 销售运营部 |

### 4.3 异议处理

1. 伙伴在门户提交异议时，须选择原因（金额错误/归属错误/客户取消/其他）并附说明。
2. 销售运营部 5 个工作日内复核，必要时调阅 CRM 日志与客户付款凭证。
3. 异议处理结果不可直接修改对账单，需通过"调整单"在下月对账单中体现差额（红冲或补提）。
4. 异议金额涉及 ≥ ¥10,000 的，必须经销售运营总监 + 财务总监双签。

## 五、风控与红线

### 5.1 返点扣减触发条件

| 触发条件 | 扣减比例 / 动作 |
|---|---|
| 被推荐客户在 **首次付款后 30 天内** 退款 | 该笔激活提点 **全额扣回** |
| 被推荐客户在 **首次付款后 31–90 天内** 退款 | 该笔激活提点 **扣回 50%** |
| 经核实存在"刷单"、"自己注册自己推荐"等舞弊行为 | **全额扣回 + 取消 Partner ID + 列入黑名单** |
| PAYG 客户连续 3 个月零使用 | 该客户对应的 D 类返点 **扣回 50%**（防套利） |
| 续费率连续 2 个季度 < 40% | 该伙伴等级 **下调一档**（A→B→C） |

### 5.2 反舞弊机制

- 设备指纹、IP、手机号、对公账户去重比对，疑似关联客户自动标记
- 同一法人/同一实控人企业互荐 → 不计入返点
- 第三方反舞弊审计抽查比例 ≥ 5%/月

## 六、激励机制（拉伙伴主动性）

### 6.1 月度榜单

- **TOP 10 激活伙伴**：奖金加成 **+10%**，公示于公司官网"渠道之星"
- **TOP 3 大客户激活伙伴**：奖金加成 **+15%** + 高管见面会
- **新晋伙伴月度新人王**：奖金 ¥2,000 + 升级一档

### 6.2 季度激励

- 单季激活客户数 ≥ 100 家：奖品/奖金 ¥30,000
- 单季增值订单贡献 ≥ ¥50,000：奖品/奖金 ¥20,000
- 全季零异议、零退款：额外 ¥5,000 "金牌服务"奖

### 6.3 年度评级

| 等级 | 年度激活家数 | 年度返点总额 | 待遇 |
|---|---|---|---|
| 钻石 | ≥ 500 家 | ≥ ¥200,000 | 独家区域 + 总裁年会 |
| 金牌 | 200–499 家 | ≥ ¥80,000 | 优先支持 + 培训认证 |
| 银牌 | 50–199 家 | ≥ ¥20,000 | 月度运营支持 |
| 铜牌 | < 50 家 | — | 基础支持 |

## 七、与销售提成的边界（避免双算）

| 客户来源场景 | 销售提成 | 渠道返点 |
|---|---|---|
| 销售直接拓客（无 Partner ID）| 30% 激活 + 5% 续费 | 0 |
| 渠道带客后转交销售跟进 | 销售拿 10%（执行奖）| 渠道按 2.2 表全额 |
| 客户自助注册带 Partner ID | 0 | 渠道按 2.2 表全额 |
| 客户自助注册无 Partner ID | 公司平摊"市场费用"，无人计提 | 0 |
| 销售自带渠道码进行"代客签约" | 视为销售直拓 | **禁止**（红线，违规取消提成）|

> CRM 系统在订单生成时自动判定归属并计算提成/返点，**不可手工调整**；如确有特殊情况，须销售总监 + 渠道总监 + 财务总监三方书面签批。

## 八、信息系统与数据规范

### 8.1 必备系统打通

- CRM（客户归属、订单金额、Partner ID 追踪）
- 财务 ERP（应付账款、付款执行）
- 渠道伙伴门户（对账单、推广素材、二维码下载）
- 数据仓库（月度榜单、舞弊检测）

### 8.2 关键字段

每条订单记录须包含：
- `order_id`、`customer_id`、`customer_tier`（小微/中型/大型/集团）
- `partner_id`、`partner_type`（A/B/C/D）
- `order_type`（首付/续费/增值）
- `order_amount`、`paid_at`
- `commission_calculated`（系统计算返点金额）
- `commission_status`（待对账/已确认/已结算/已扣回）

### 8.3 报表

每月 1 日自动生成：
- 各伙伴月度对账单（含明细）
- 公司层面"渠道贡献漏斗"
- 异议明细 + 处理状态
- 年度累计 + 等级动向

## 九、税务与合规

1. **A/B 类**（对公）：伙伴开具"信息技术服务费"6% 增值税专用发票 → 公司付款 → 入"销售费用-渠道返点"科目
2. **C 类**（个人独立 BD）：
   - 月度返点 < ¥800：直接入卡
   - 月度返点 ≥ ¥800：代扣劳务报酬个人所得税，伙伴须提供身份证 + 收款账户 + 个人完税证明
   - 鼓励 C 类伙伴注册个体工商户 / 灵活用工平台开票
3. **D 类**（客户老带新）：以"年费抵扣券"形式发放，**不构成现金收入**，不涉及个税，但需在客户合同/补充协议中明确"奖励性质"
4. 所有结算附"《付款明细 + 完税声明》"双签 PDF 留档

## 十、变更管理

1. 本规则由销售运营部 + 财务部联合修订；任何修订须营销总裁审批后下发。
2. 修订生效前 15 天向全部已签约伙伴公示；
3. 修订仅适用于公示日之后产生的订单，**已发生订单按原规则结算**；
4. 修订版本号：v2.x；每次调整须留版本对比文档。
