# 季度业务复盘看板设计（CEO / CFO / 营销总裁三视图）

> **战略地位**：v2 战役必须靠"季度复盘"持续校准；如果只看月度收入、不看战略漏斗，半年就会跑偏。  
> **本文件用途**：定义三个角色的看板内容、指标体系、阈值告警、复盘节奏、决策模板  
> **覆盖工具**：内部数据驾驶舱（建议 Quick BI / Tableau / DataV / 自研）  
> **核心 KPI**：复盘准时率 100%、阈值告警响应 ≤ 24 小时、季度战略校准 ≥ 2 项

---

## 一、为什么要"三视图"

不同角色看不同的数字：

| 角色 | 关心的本质 |
|---|---|
| **CEO** | 战略漏斗是否打通？三条曲线是否健康？需要把方向盘转哪个方向？ |
| **CFO** | 现金流、毛利、单位经济模型、ROI、安全垫 |
| **营销总裁** | 获客、转化、留存、裂变、客单价、销售/渠道效率 |

> **三个视图必须共享底层数据**，但**各自聚合维度不同**——避免"每个人看到的真相不一样"。

### 2.3 三条曲线（公司未来 5 年的"心电图"）

| 曲线 | 描述 | 季度变化阈值 |
|---|---|---|
| **工具订阅曲线** | 提货宝+对账宝订阅 ARR | < +20% QoQ → 🟡 |
| **货袋子撮合曲线** | 撮合 GMV + 佣金收入 | < +30% QoQ → 🟡 |
| **ERP 商机曲线** | ERP 触发数 + POC 数 + 签约数 | 任何衰退 → 🔴 |

### 2.4 战略告警区（CEO 必须本季关注的 5 件事）

- 🔴 若漏斗某层转化率 < 上季 70% → 自动告警 + 触发产品/销售复盘
- 🔴 若货袋子 GMV 同比 < 50% → 启动产品战略评估
- 🔴 若 ERP 商机数月环比连续 2 月下降 → 启动客户成功诊断
- 🟡 若客户成功 NPS 下降 5 分 → 触发 CSM 复盘
- 🟡 若任一区域 / 任一客群营收占比 > 50% → 警惕单点依赖

### 2.5 季度战略决策模板

每季度 CEO 必填的 3 个决策：

1. **本季度最关键的 3 个数字** + 为什么变化（不超过 100 字）
2. **本季度战略 1 个明显跑偏，需要校准的方向**
3. **下季度公司资源最需要倾斜到哪个漏斗层**

## 六、季度复盘流程（必须刚性执行）

### 6.1 时间安排（不写具体几天，写节点）

```
节点 1：季度末前 7 天
  → 数据冻结，自动出报告
节点 2：季度末前 3 天
  → 三视图各自完成"决策模板"
节点 3：季度末当日
  → 高管层季度复盘会（4 小时）
节点 4：季度末后 3 天
  → 复盘纪要 + 下季度作战图全员发布
节点 5：季度末后 30 天
  → 校准动作完成度复盘
```

### 6.2 季度复盘会议程（4 小时固定）

| 时段 | 内容 | 主讲 |
|---|---|---|
| 0:00–0:30 | CEO 视图汇报 | CEO |
| 0:30–1:00 | CFO 视图汇报 | CFO |
| 1:00–1:30 | 营销总裁视图汇报 | 营销总裁 |
| 1:30–2:00 | 客户成功 NPS + 标杆案例 | CSM 主管 |
| 2:00–2:30 | 产品 / 实施进展 | 产品总监 |
| 2:30–3:00 | 各部门关键告警与跨部门请求 | 各部门 |
| 3:00–3:30 | 战略校准讨论（重点议题 ≤ 3 个）| 全员 |
| 3:30–4:00 | 下季度 KPI 与作战图签字确认 | CEO |

### 6.3 复盘"3 必谈"

1. **数字背后的人**：每个 KPI 不达标都要回到"是哪个团队/哪个人/哪个客户"
2. **失败的复盘**：失败比成功更值得复盘，专门留 30 分钟讲"最大的失败"
3. **下季度 1 个核心问题**：用一句话锁定下季度全公司唯一最关键的事

## 七、告警机制（不依赖人工）

| 告警 | 触发 | 接收人 | SLA |
|---|---|---|---|
| 🔴 战略漏斗某层转化率周环比下降 30% | 自动 | CEO + 营销总裁 | 24 小时复盘 |
| 🔴 现金安全垫 < 6 个月 | 自动 | CEO + CFO | 立即复盘 |
| 🔴 大客户回款逾期 > 30 天 | 自动 | CFO + 销售总监 | 24 小时启动催收 |
| 🟡 NPS 下降 5 分 | 自动 | CSM 主管 + 营销总裁 | 1 周诊断 |
| 🟡 某区域 / 某客群营收占比 > 50% | 自动 | CEO + 营销总裁 | 1 月战略评估 |
| 🟡 老带新裂变率 < 50% | 自动 | 营销总裁 | 1 月专项 |
| 🟡 KOL 单条 ROI < 1 | 自动 | PR 总监 | 立即停投 |

## 八、数据治理与口径

### 8.1 数据来源

- CRM（客户、订单、续约、流失）
- 财务 ERP（应收、付款、毛利）
- 业务系统（提货宝/对账宝/货袋子使用量）
- 客户成功系统（NPS、活跃度、CSM 工时）
- 公关 / 媒体投放（曝光、CTR、转化）

### 8.2 口径治理

- **每季度第 1 个月**：数据治理委员会例会，统一关键口径
- 任何指标新增 / 修改 → 数据治理委员会签字
- 历史口径变更必须"双轨"显示 ≥ 3 个月

### 8.3 数据质量

- 每月质量报告：完整性、及时性、准确性
- 数据错报追责 SOP
- 每季 1 次第三方数据审计

## 十、一句话总结

> **季度复盘看板是公司战略的"导航仪"**。  
> 没有看板 → 老板看月度收入开心 → 半年后漏斗崩了才发现 → 校准已晚。  
> 有看板 → 每季看转化、看裂变、看 LTV → 校准在前 → 战略不会跑偏。
