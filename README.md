## 推广骨架（速查）

1. **链式裂变**：每笔提货 → 触达下游 → 一键开通 → 三层覆盖
2. **老带新返费**：1 / 3 / 10 / 30 家四档奖励
3. **种子加速**：钢贸物流园 + 行业协会 + 头部钢厂下沉授权
4. **后端转化漏斗**：提货宝/对账宝 → 货袋子 → ERP

## 三年 LTV 视角（v2）

| 维度 | 三年累计 |
|---|---|
| 工具订阅收入 | ~0.9 亿 |
| 货袋子撮合佣金 | **~4.5 亿** |
| ERP 订阅收入 | **~2.4 亿** |
| 增值服务（OCR/存证/API）| ~1.2 亿 |
| **合计** | **~9.0 亿** |

> 工具侧少赚 1,000 万左右，但三年 LTV 多 5 亿+。

## 版本历史

- **v2（当前）**：所有套餐下调 60–80%，新增 PAYG 按量计费兜底版，强化"工具获客 + 后端变现"模型。
- v1：高订阅价（小微 2,280 起），偏离钢贸真实支付意愿（已废弃）。
