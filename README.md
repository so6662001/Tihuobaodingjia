## 核心思想（双产品矩阵）

> **双宝是"门票"，ERP/WMS 是"VIP 包房"**——双宝几乎不赚钱负责沉淀客户，ERP + WMS 把已经在我们这里 1–2 年的客户自然升级为长期合作伙伴。  
> **库准 WMS 是独家武器**，是 ERP 推不动时撬开大客户的"硬入口"。  
> **v2.2 救场版核心**：钢贸客户"现场拍板价" = 年利的 3% 不到。**降价 40–55% 不是亏钱，是让客户基数翻 2.3 倍。**
