## 核心思想（一句话回顾）

> **不卖软件，卖"少亏的钱"。**  
> 提货宝 + 对账宝是低价高频的"获客武器"，目的在于沉淀实名客户、撬动链式裂变，并把客户引流至货袋子与未来 ERP，构建长期 LTV。

## 定价骨架（速查）

- **提货宝**：免费版 / 标准 ¥1,980 / 专业 ¥4,980 / 旗舰 ¥9,980 / 集团 ¥29,800
- **对账宝**：免费版 / 标准 ¥1,280 / 专业 ¥3,280 / 旗舰 ¥6,980 / 集团 ¥19,800
- **双宝套餐**（主推）：单买价的 **7 折** + 货袋子权益
- **增值收费**：3 年以上证据存档、人脸签、OCR 上链、API 对接

## 推广骨架（速查）

1. **链式裂变**：每笔提货 → 触达下游 → 一键开通 → 三层覆盖全行业
2. **老带新返费**：1 家 / 3 家 / 10 家 / 30 家四档奖励
3. **种子加速**：钢贸物流园 + 行业协会 + 头部钢厂下沉授权
4. **后端转化**：提货宝/对账宝 → 货袋子 → ERP

## 使用建议

- **第一次接触客户**：用 `02-销售话术手册.md` 中"算账模板"开场。
- **拜访客户管理层**：用 `01-PPT提案大纲.md` 第 1~10、20~22 页。
- **市场投放与官网改版**：直接采用 `03-价格公示页文案.md`，注意上线 Checklist。
