## 核心思想（双产品矩阵）

> **双宝是"门票"，ERP/WMS 是"VIP 包房"**——双宝几乎不赚钱负责沉淀客户，ERP + WMS 把已经在我们这里 1–2 年的客户自然升级为长期合作伙伴。  
> **库准 WMS 是独家武器**，是 ERP 推不动时撬开大客户的"硬入口"。

### 双宝抵扣机制（核心战略联动）
- 客户购买 ERP/WMS 时，**过去 24 个月双宝订阅金额可 100% 抵扣 ERP/WMS 首年应付**（上限套餐价 30%）
- 让双宝订阅变成 ERP 首付 → 客户感受"双宝白用 + ERP 降价"

### 货袋子撮合佣金（后端中段变现）
- A 自助 0.10% / B 顾问 0.20% / C 集采 0.30%
- ERP/WMS 套餐客户再减 10%

### 多年付折扣（拉长 LTV）
- 2 年付 92 折 / **3 年付 85 折 + 永久授权** / 5 年付 78 折 + 私有部署权

## 三年 LTV 视角（v2）

| 维度 | 三年累计 |
|---|---|
| 工具订阅收入（双宝）| ~0.9 亿 |
| 货袋子撮合佣金 | **~4.5 亿** |
| **ERP + WMS 订阅** | **~1.2–1.8 亿** |
| 增值服务（OCR/存证/API/私有化）| ~1.2 亿 |
| **合计** | **~7.8–8.4 亿** |

> 与早期 9.0 亿预测对齐：双宝战略闭环让 ERP/WMS 实现 800 家客户，800 家 × 平均 ¥150,000 套餐 / 3 年 = ~¥1.2 亿；加 WMS 单卖贡献，整体 ¥1.8 亿规模。

## 三大市场异议回应（销售必背）

1. **"金蝶比你们便宜！"** → 5 年 TCO 对比（金蝶 + 二开 = ¥30 万；我们全家桶 = ¥4.58 万/年）
2. **"我已经有 ERP，不想换。"** → 先卖 WMS（独家产品 + 效率 +20% 承诺）
3. **"市场都是一次性，无年服务费。"** → 双轨双选 + 封顶版（小微无限用户 ¥9,800/年）
