## 推广骨架（速查）

1. **链式裂变**：每笔提货 → 触达下游 → 一键开通 → 三层覆盖
2. **老带新返费**：1 / 3 / 10 / 30 家四档（详见 `07`）
3. **种子加速**：钢贸物流园 + 行业协会 + 头部钢厂下沉授权
4. **后端转化漏斗**：永久免费 → PAYG → 双宝订阅 → 货袋子 → ERP
